# neisora 0.8.1 — нижний плеер и системные метаданные

В нижнем плеере Play теперь совпадает с центром таймлайна: shuffle и repeat располагаются по разные стороны навигации. Лайк остаётся рядом с метаданными трека, а не у дальнего края растянутой колонки. Проверена геометрия на 420–1920 px, в том числе с длинным названием.

Смена трека и статуса отправляется в системные медиа-интерфейсы сразу; частые обновления позиции по-прежнему объединяются. Linux D-Bus обслуживается одним потоком, который явно отправляет накопленные сигналы. Раньше сигнал мог оставаться в буфере до следующего запроса от панели.

Новая регрессия подписывается на PropertiesChanged без запросов свойств во время замера: задержки после исправления составили 30–80 мс в изолированных прогонах. Отдельная проверка нажатия Next в интерфейсе до получения пассивного уведомления заняла около 75 мс. Прежняя проверка чтением Metadata скрывала проблему, поскольку сама будила обработчик D-Bus. Настройки системной панели не менялись.
