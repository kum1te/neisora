# neisora 0.8.0 — очередь и продолжение прослушивания

Тестовая сборка; публикация стабильного релиза отдельно.

- Shuffle в обычном и большом плеере: перемешиваются только следующие треки. Текущий и уже проигранные остаются на месте, дубли сохраняются. Выключение возвращает исходный порядок оставшейся части. Перед перемешиванием загружаются продолжения плейлиста; при ошибке перемешивание не включается. Живые рекомендации YouTube не перемешиваются локально.
- Восстановление трека, позиции и загруженной очереди после перезапуска, всегда на паузе. Громкость уже сохранялась отдельно. При Play mpv получает позицию до снятия паузы; адрес потока извлекается заново.
- Супермикс сохраняет текущий трек и ручные добавления. При продолжении запрашивается новая очередь с новым контекстом YouTube. Старые рекомендации и токены не сохраняются; восстановление не отправляет фиктивный skip.
- Сохранение ограничено 2000 записями вокруг текущего трека. При восстановлении неполного или большого плейлиста интерфейс предупреждает, что восстановлена загруженная часть. Продолжения сервиса не сохраняются.
- Очередь: поиск с количеством совпадений, выбор нескольких треков, групповое удаление, очистка следующих и отмена последнего удаления в течение 30 секунд. Очистка останавливает дальнейшее автоматическое пополнение; текущий трек продолжает играть. Отмена недоступна после смены трека, другого редактирования или обновления радио.
- Обычные строки очереди сохранили две кнопки без фона, появляющиеся при наведении: убрать и перетащить. Флажки появляются только в режиме выбора.

Очередь атомарно сохраняется Rust в `playback-session.json` с приватными правами; запись подтверждается после сброса файла на диск и не зависит от отложенной записи WebKit. Сохранённые данные содержат проверенные ID и ограниченные метаданные. Cookie, приватные токены, пути файлов, команды и адреса потоков в них не попадают. Локальные файлы проверяются существующим механизмом разрешения ID при воспроизведении; отключённый диск вызывает понятную ошибку и не получает произвольного доступа к файловой системе. Выход из аккаунта очищает сохранённую очередь.
