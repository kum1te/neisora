# neisora на Linux

Пакеты: Linux **x86_64**, минимальная база glibc **2.35** (Ubuntu 22.04). ARM64, Windows и macOS пока не выпускаются. Окружения разных дистрибутивов проверяются [workflow Linux](https://github.com/kum1te/neisora/actions/workflows/linux.yml); успешный запуск в CI не заменяет проверку аудиоустройств и драйверов на конкретном компьютере.

## Установка

Скачай пакет и `SHA256SUMS` из одного [релиза](https://github.com/kum1te/neisora/releases). В каталоге загрузки:

```sh
sha256sum --check --ignore-missing SHA256SUMS
```

| Система | Команда |
| --- | --- |
| Ubuntu 22.04+ / Debian 12+ | `sudo apt install ./neisora_1.0.0_amd64.deb` |
| Fedora | `sudo dnf install ./neisora-1.0.0-1.x86_64.rpm` |
| Arch / EndeavourOS | `sudo pacman -U ./neisora-1.0.0-1-x86_64.pkg.tar.zst` |

Пакетный менеджер устанавливает GTK 3, WebKitGTK 4.1, mpv и Python 3. Для цветов обоев дополнительно установи ImageMagick. Node.js и yt-dlp уже включены; ставить npm, Rust или отдельный модуль Python для yt-dlp не требуется.

После установки запусти **neisora** из меню или командой `neisora`. В Настройках доступны вход через Google и явный импорт сессии браузера. Google может отклонять встроенное окно входа: тогда используй импорт из поддерживаемого установленного браузера. Данные входа остаются локально.

## AppImage

Скачай `neisora_1.0.0_amd64.AppImage`, разреши запуск и открой:

```sh
chmod +x neisora_1.0.0_amd64.AppImage
./neisora_1.0.0_amd64.AppImage
```

AppImage включает mpv, Python, Node, yt-dlp и библиотеки интерфейса. Устанавливать их отдельно не нужно. Минимальная база — glibc 2.35, нужен работающий графический сеанс с библиотеками драйвера и системный аудиостек (библиотеки ALSA и PulseAudio; сервером может быть PipeWire). GTK/WebKit, mpv и Python отдельно устанавливать не нужно. Цвета обоев по-прежнему требуют внешнего ImageMagick. Если FUSE 2 недоступен, запускай без монтирования:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./neisora_1.0.0_amd64.AppImage
```

HTTPS использует доверенные сертификаты системы, включая стандартные пути Ubuntu/Debian, Fedora и Arch; проверка сертификатов не отключается. Упакованный Python не подхватывает пользовательские Python-модули.

Графический сеанс AppImage использует X11; в Wayland нужен XWayland. Библиотеки драйвера, ALSA/PulseAudio, Fontconfig и системные утилиты берутся из ОС, без глобальной подмены путей библиотек.

Профиль общий с обычной установкой: вход и оформление сохраняются. Закрой другой экземпляр neisora перед запуском. Для обновления замени AppImage новым файлом. Файл примерно 180–200 МБ: внутри также библиотеки WebKit и аудиодекодеры.

## Переносимый архив

Распакуй `neisora-linux-x86_64.tar.gz` и запусти `./neisora/neisora`. Сохраняй рядом каталоги `runtime` и `licenses`. Архив **не самодостаточный**: нужны glibc 2.35+, GTK 3, WebKitGTK 4.1, mpv 0.34+ и Python 3.10+. На Alpine/musl такая сборка не работает.

## Графика и обои

На Wayland с обнаруженным NVIDIA по умолчанию применяется обход несовместимости WebKit DMABUF. На других системах остаются штатные настройки WebKit. При необходимости:

```sh
NEISORA_RENDERER=safe neisora   # совместимый режим
NEISORA_RENDERER=native neisora # штатный renderer WebKit
```

Перед сменой режима закрой предыдущий экземпляр. В Настройках отображаются версия и активность режима совместимости. Режим совместимости не снижает разрешение и детализацию визуализатора. Волны рисуются через WebGL со сглаживанием; если WebGL недоступен, используется Canvas 2D. Частота следует кадрам WebView без искусственного ограничения 12–25 FPS. При паузе, закрытом плеере и скрытой странице отрисовка прекращается. Флаг `LIBGL_ALWAYS_SOFTWARE=1` может принудительно переводить графику Mesa на CPU, в том числе WebGL; наличие WebGL само по себе не доказывает использование GPU. Визуализатор можно отключить.

Поиск локальных обоев реализован для GNOME, Cinnamon, MATE, KDE Plasma, XFCE и QuickShell / Illogical Impulse. Неопределяемые, удалённые, видеообои и несколько разных обоев на мониторах могут требовать ручной цветовой схемы. Обои не отправляются в сеть. Для извлечения палитры нужен `magick` либо `convert` из ImageMagick.

## Медиаклавиши

neisora регистрируется в пользовательской D-Bus-сессии как `org.mpris.MediaPlayer2.neisora`. Совместимые панели GNOME, KDE и другие MPRIS-клиенты видят название, обложку, состояние, длительность и позицию трека. Управление работает без фокуса окна, пока приложение запущено.

Если оконный менеджер не привязывает аппаратные медиакнопки к MPRIS автоматически, используй его штатные настройки сочетаний клавиш и команды `playerctl`:

```sh
playerctl --player=neisora play-pause
playerctl --player=neisora next
playerctl --player=neisora previous
playerctl --player=neisora stop
```

Приложение не перехватывает клавиатуру и не редактирует конфигурацию рабочего стола. Системные клавиши громкости продолжают управлять громкостью ОС; регулятор MPRIS меняет громкость neisora. Без пользовательской D-Bus-сессии музыка и интерфейс работают, а системное управление недоступно.

## Обновление и удаление

Установи новый пакет поверх старого. Идентификатор профиля `local.kumite.vesper` сохранён после переименования: вход и оформление сохраняются. Закрой раннюю версию перед первым запуском обновления.

Удаляй через свой пакетный менеджер (`apt remove neisora`, `dnf remove neisora`, `pacman -R neisora`). Профиль намеренно остаётся в `${XDG_CONFIG_HOME:-~/.config}/local.kumite.vesper`; для удаления входа используй выход в Настройках. Локальная установка `tools/install.sh` хранит версии в `~/.local/lib/neisora`, launcher в `~/.local/bin/neisora`, desktop entry в `~/.local/share/applications/neisora.desktop`.

Автообновления пока нет. Обновления включённых Node.js и yt-dlp поставляются вместе с приложением. Бинарные пакеты пока без криптографической подписи; SHA256SUMS проверяет целостность, но не заменяет подпись издателя.

## Диагностика

При ошибке сообщи версию, дистрибутив, X11/Wayland, GPU и название проблемного трека. Не публикуй cookies, профиль, Google-адрес аккаунта или подписанные URL медиапотоков. Логи и секреты не должны попадать в issue.

Известные ограничения и область проверок: [состояние релиза](BETA.md), [безопасность](SECURITY.md). YouTube Music использует неофициальный API; доступность сервиса и его изменения находятся вне контроля приложения.
