# neisora 0.9.0 — таймер сна и сохранение очереди

Поле доступа в окнах создания и изменения плейлиста заменено на три варианта с иконками: **Личный**, **По ссылке**, **Открытый**. Цвета берутся из темы neisora; системный светлый select больше не скрывает подпись. По умолчанию новый плейлист личный, при редактировании сохраняется текущий доступ.

В меню **Очередь → ⋯ → Сохранить как плейлист** можно сохранить загруженные треки YouTube Music в аккаунт. Порядок и повторы сохраняются. Перед созданием показано количество треков; локальные файлы не загружаются в YouTube, незагруженное продолжение не включается. За одно создание поддерживается до 2000 треков. Нужен вход в YouTube; ошибки сохраняют форму открытой для повтора.

**Таймер сна** доступен в настройках и меню очереди. Есть готовые интервалы, своё время от 1 до 1440 минут и остановка после естественного окончания трека. При пропуске трека последний режим дожидается окончания следующего. Таймер выполняется в Rust, включая свёрнутое окно, и имеет приоритет над repeat и автоматическим продолжением. Музыка ставится на паузу без изменения громкости. После срабатывания можно вручную продолжить воспроизведение. После перезапуска таймер выключен.

Эта версия не добавляет кнопок в нижний плеер. Затухание громкости и синхронизация таймера между устройствами пока не реализованы.
