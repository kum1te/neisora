# neisora. — Windows test build

Тестовая сборка для Windows 10 (1809+) / 11, x64. Это ещё не стабильный Windows-релиз.

Запусти `neisora_1.0.0_x64-setup.exe`. Права администратора не нужны. **Во время установки нужен интернет**: установщик скачает WebView2 при необходимости и закреплённый mpv напрямую с GitHub, проверив SHA-256. Системный Python, Node и mpv устанавливать не нужно. Пакет пока не подписан, поэтому Windows может показать предупреждение о неизвестном издателе; сверяй источник и `SHA256SUMS`.

Уже проверены на чистой Windows VM: сборка, установка NSIS, запуск настоящего WebView2, локальная коллекция с русскими/японскими путями, воспроизведение mpv без аудиоустройства, перемотка, громкость, синхронный LRC и следующий трек. Реальное устройство, Google и GPU проверяются именно этой тестовой сборкой.

Пожалуйста, проверь:

1. Первый запуск, вход Google через настройки и появление твоих рекомендаций.
2. Воспроизведение музыки YouTube и локальных файлов с реальным звуком, перемотку, громкость, паузу и следующий трек.
3. Супермикс при нескольких пропусках, текст песен и визуализатор.
4. Медиаклавиши при свёрнутом окне, пробуждение после сна, разные масштабы экрана.
5. Повторный запуск, обновление поверх установленной версии и удаление через настройки Windows.

При ошибке пришли версию Windows, масштаб экрана, последовательность действий, название трека и скриншот. Не отправляй cookies, профиль WebView2 и данные Google.

Исходники: https://github.com/kum1te/neisora/tree/main

Проверь также shuffle в обычном плейлисте и возврат порядка повторным нажатием. Закрой приложение на середине трека, открой снова: трек и позиция должны восстановиться на паузе. Для супермикса новые рекомендации появляются при продолжении. В очереди меню ⋯ содержит групповое удаление и очистку следующих; отмена доступна до смены трека/очереди.
