# neisora 0.7.1 — добавление треков из плейлиста

В своём плейлисте появилась кнопка **Добавить треки**, в том числе когда плейлист пустой. Поиск YouTube Music открывается внутри окна: можно добавить несколько треков, видеть подтверждение рядом с каждым и затем нажать **Готово**. Список плейлиста обновляется после закрытия окна.

Запоздавший ответ старого поиска не заменяет новые результаты. Ошибка добавления оставляет окно открытым для повторной попытки; счётчик и галочка меняются только после подтверждения сервера. Повторный клик по уже добавленному в этом окне треку отключён. Локальные файлы и результаты альбомов/исполнителей не предлагаются.

Создание плейлиста и его появление в обычном YouTube Music подтверждено пользователем на настоящем аккаунте. Добавление из нового окна проверяется автоматизированно в изолированном WebKit с тестовыми ответами; пользовательские плейлисты тесты не изменяют.

Windows-установщик 0.7.0 остаётся отдельной тестовой сборкой: в нём добавление доступно из меню трека и большого плеера. Новая кнопка внутри плейлиста появилась в исходниках 0.7.1.
