# Linux 0.6.x — проверка выпуска

Это отдельный выпуск после 0.5.0; опубликованные старые теги и пакеты сохраняются. Рабочий профиль и Google cookies пользователя не используются в разрушающих проверках.

Кандидат 0.6.0 остановлен CI из-за гонки в тесте, ожидавшем только название трека. В 0.6.1 тест ждёт окончания загрузки; сценарий дополнительно проверяется с искусственной задержкой воспроизведения. Тег 0.6.0 не перемещается.

## Состав

Лайки и медиатека YouTube Music, Linux MPRIS, локальная история, папки локальной музыки с тегами/обложками/LRC, смешанные редактируемые очереди. Полноразмерный WebGL-визуализатор, подбор текстов и обложек, скрытие текста в большом плеере. Подробнее: [локальная музыка](LOCAL-MUSIC.md), [тексты](LYRICS.md).

## Проверки

- Svelte/TypeScript: без ошибок и предупреждений; восемь тестов очереди.
- Rust: 52 теста проходят; два сетевых теста с внешними провайдерами/аккаунтом не запускаются по умолчанию. Форматирование и Clippy с запретом предупреждений.
- WebKit/Xvfb: полный прогон интерфейса, настоящее перемещение мышью через xdotool, скрытие текста/центрирование, отказ и восстановление WebGL, гонки ответов, коллекция/MPRIS/история, нативный диалог папки и mpv, 10 000 строк очереди, lifecycle и отрицательные IPC/CSP/XSS-сценарии. Полный прогон прошёл: 24 отрицательные проверки, 100 циклов, DOM 6405→6405, IPC-listeners 12→12, RAF после закрытия 0, fd дерева 113. PSS в этом headless-прогоне 531–616 МиБ; последняя выборка 550 МиБ. Это ограниченная проверка, а не гарантия отсутствия любых утечек.
- Production: Ubuntu 22.04 / glibc 2.35 — минимальная база сборки. Пакеты .deb/.rpm/Arch и переносимый архив; контрольные суммы и состав пакетов проверяются отдельно.
- CI установки: Ubuntu 22.04/24.04, Debian 12, Fedora 44, Arch. Локальный прогон не заменяет результаты этой матрицы; статус виден в GitHub Actions.

## Проверка исходников перед загрузкой

`detect-secrets`: 96 срабатываний просмотрены — публичные контрольные суммы, фиктивные ID/URL с `user:pass`, upstream-тесты и имя `BadPassword`. Действующих секретов в проверяемых исходниках не найдено. Cookies, профили, логи, runtime, node_modules и результаты сборки исключены из Git. `pnpm audit`: известных уязвимостей нет. Cargo audit: 0 vulnerabilities; два предупреждения unmaintained — `paste` и `proc-macro-error`.

## Ограничения

Windows/macOS не входят в этот выпуск. Автоматического обновления и криптографической подписи пакетов нет. Проверка по SHA-256 подтверждает целостность файла, а не доверие издателю. Проверки с отключённым аудиовыходом не подтверждают работу всех Bluetooth-устройств, драйверов и длительного suspend/resume. Синхронные тексты зависят от наличия настоящих таймкодов у источника.
