# Следующие функции neisora

В 0.6.x появились медиаклавиши, локальная коллекция, история и управление очередью. В 0.7.x добавлены повтор, управление плейлистами YouTube Music и интерфейс для узких окон. В 0.8.0 — shuffle, восстановление сессии и групповое управление очередью. В 0.9.0 — таймер сна и сохранение очереди как плейлиста; см. [заметки 0.9.0](RELEASE-0.9.0.md).

## Согласованная следующая очередь

Выбраны пользователем после 0.9.0:

1. **Реализовано в 0.10.0:** ссылки на треки, альбомы и плейлисты: скопировать / открыть в YouTube Music.
2. **Реализовано в 0.10.0:** диагностика: понятные этапы сбоя и копируемый отчёт без сессий, URL потоков, путей и персональной истории.
3. **Реализовано в 1.0.0:** выбор версии текста с предпросмотром, сохранением и возвратом к автоматическому подбору. Смещение сохраняется отдельно для выбранной версии.
4. **Реализовано в 1.0.0:** выбор аудиовыхода, временный системный выход при отключении и возврат при подключении.
5. **Отложено пользователем:** мини-плеер с общей с основным окном очередью и состоянием воспроизведения.
6. **Отложено пользователем:** gapless: заранее подготовленный следующий трек и переход силами плеера; отдельно проверить локальные альбомы, YouTube, repeat, таймер сна и динамическую очередь. Один флаг mpv или предварительное получение URL не считаются готовой реализацией.

Поиск/сортировка внутри плейлиста, сохраняемые смешанные локальные плейлисты и затухание таймера отложены по решению пользователя. Готовые функции не удаляются. Портирование остаётся отдельным направлением.

## Реализовано и следующие кандидаты

| Приоритет | Функция | Как должна работать |
| :--- | :--- | :--- |
| 0.8.0 | **Shuffle** | Перемешать обычный плейлист или локальную очередь, сохранив текущий трек и возможность вернуть исходный порядок. Живой супермикс не заменять случайной локальной перестановкой. |
| 0.8.0 | **Восстановление сессии** | Вернуть очередь, трек, позицию и громкость после перезапуска; запускаться на паузе, проверить доступность локальных файлов и заново получать адреса YouTube-потоков. |
| 0.9.0 | **Таймер сна** | Пауза через заданное время или после естественного окончания трека; работает нативно, сохраняет громкость. Затухание пока не реализовано. |
| 0.9.0 | **Сохранить очередь как плейлист** | Загруженные YouTube-треки в текущем порядке, с пояснением о локальных файлах и продолжении. |
| P1 | **Поиск и сортировка внутри плейлиста** | По названию, исполнителю, альбому; сортировку представления не путать с изменением порядка в аккаунте. |
| 0.10.0 | **Поделиться / открыть в YouTube Music** | Копирование ссылки на трек, альбом и плейлист; открывать только проверенные адреса сервиса. |
| P2 | **Мини-плеер** | Небольшое окно с обложкой и основными действиями, с учётом ограничений разных оконных менеджеров. |
| P2 | **Выбор аудиовыхода** | Наушники, Bluetooth, колонки и восстановление после переподключения. |
| P2 | **Выбор версии текста** | Выбрать подходящую запись и сохранить смещение. Показывать караоке только с настоящими таймкодами. |
| P2 | **Gapless** | Смена треков без искусственной паузы; проверить на реальных потоках и альбомах. |
| 0.10.0 | **Обезличенная диагностика** | Показать этап проблемы и скопировать отчёт без cookies, подписанных URL и личных подборок. |
| Исследование | **Возможно**, другие площадки | Сначала проверить доступные API, авторизацию и воспроизведение. Поддержка конкретного сервиса не обещана. |

Сначала проверить Windows beta с реальным звуком, Google и аппаратными медиаклавишами у тестеров. Приоритеты следующей итерации перечислены выше; поиск внутри плейлиста и смешанные сохраняемые плейлисты отложены. macOS требует отдельной нативной сборки и проверки; Linux AppImage уже опубликован в 0.6.3.
