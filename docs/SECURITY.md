# Безопасность

Локальная музыка: папки подключаются через системный диалог; IPC воспроизведения/обложек/LRC принимает ID индексированной записи, а не произвольный путь. Символьные ссылки не сканируются, принадлежность подключённой папке проверяется перед открытием, у mpv отключено следование вложенным ссылкам. Локальные тексты/обложки читаются без запросов к внешним каталогам; изображения перекодируются с ограничением памяти. [Подробности](LOCAL-MUSIC.md#границы-доступа).

Локальная история хранится в защищённом профиле (`history.json`, права 0600), ограничена 500 записями и не содержит исходных команд радио или токенов очереди. MPRIS доступен в пользовательской D-Bus-сессии: другие приложения этого пользователя могут видеть метаданные текущего трека и управлять плеером. Внешние URL через MPRIS не открываются; команды не запускают shell.

Актуальные исправления, повторные проверки и открытые риски: [аудит от 18 октября 2026](AUDIT-2026-10-18.md). Ниже сохранён отчёт исходной проверки 0.4.1.

## Обновление 1.0.0

Linux и Windows используют общие исходники с нативными адаптерами процессов, IPC и прав профиля. На Linux проходят 69 Rust-тестов (два внешних сетевых теста пропущены), WebKit-регрессии и отрицательные IPC/CSP/origin-сценарии. Новые команды выбора текста и аудиовыхода проверяют ID, размеры запросов и принадлежность устройства списку mpv; настройки записываются приватно. Отдельный Pulse-сервер проверяет настоящий аудиовывод и hotplug без доступа к устройствам пользователя. Статус нативной Windows-сборки и установки определяется CI; проверка на Linux его не заменяет. [Границы релиза](RELEASE-1.0.0.md).

## Обновление 0.6.0 (историческое)

Полный изолированный прогон включает 24 отрицательных IPC/CSP/XSS/origin-сценария и проверку авторизованных папок локальной музыки: обход через симлинк не разрешается, отключение папки отзывает доступ, исходные файлы сохраняются. Проходят 52 Rust-теста; два внешних сетевых теста пропущены. Рабочая Google-сессия не копируется. Результаты и ограничения выпуска — [0.6.0](RELEASE-0.6.0.md).

## Обновление 0.5.0

Для RUSTSEC-2024-0429 включён backport upstream-исправления GLib VariantStrIter; исходники, лицензия и точное происхождение находятся в [описании патча](../src-tauri/vendor/glib/NEISORA-PATCH.md). Версия crates.io не подменяется, advisory-ignore не добавляется. Cargo audit не оценивает локальную path-зависимость как новый исправленный crates.io-релиз: проверка патча и оптимизированный регрессионный тест обязательны.

Сканирование текущего исходного дерева detect-secrets: 95 срабатываний проверены вручную — публичные hashes lockfile/runtime, тестовые ID/учётные данные, upstream fixtures и имя enum BadPassword; действующих секретов не обнаружено. Сгенерированные компоненты и результаты сборки не включены в Git.

Текущий Cargo audit: 0 записей vulnerabilities, два предупреждения unmaintained — build-time proc-macro-error 1.0.4 и paste 1.0.15. pnpm audit: 0 известных уязвимостей. Это результат на дату проверки, а не гарантия безопасности.

Повторены 40 Rust-тестов, 29 проверок интерфейса и 15 отрицательных сценариев IPC/XSS/CSP/origin в отдельном неавторизованном профиле. Пакеты включают проверенные по SHA-256 Node.js и yt-dlp и лицензии зависимостей. Исполняемые обновления во время работы не скачиваются. На Linux прямые дочерние процессы получают parent-death signal; штатное завершение также останавливает управляемые группы процессов. Это не полноценная sandbox и не гарантия удаления произвольного дерева потомков при SIGKILL.

Исторические предупреждения и количества ниже относятся к 0.4.1; актуальное состояние glib — в этом разделе.

### Исправлено в этой проверке

- Файлы заменяются через уникальный временный файл с `create_new` и правами `0600`; ошибочная запись убирает временный файл. Регрессионный тест проверяет существующий симлинк и сохранность постороннего файла.
- Извлечение аудио изолировано от пользовательского конфига и расширений yt-dlp.
- Валидация ID выполняется до запуска воспроизведения; проверяются границы домена, схема, порт и userinfo медиапотока.
- Окно Google отклоняет HTTP, подменные домены, userinfo и нестандартные порты.
- Удалены неподдерживаемые `serde_yaml` / `unsafe-libyaml`; Lyricsfile разбирается через `serde-saphyr`, с лимитом входа и стандартными бюджетами парсера.

### Оставшиеся предупреждения зависимостей

**`glib 0.18.5` — [RUSTSEC-2024-0429](https://rustsec.org/advisories/RUSTSEC-2024-0429.html).** RustSec отмечает unsoundness в `VariantStrIter`. Эта версия приходит через GTK3 / WebKitGTK / Tauri. Исправление находится в glib 0.20+, который нельзя подставить в текущую GTK3-цепочку простым обновлением. Код приложения напрямую не вызывает затронутый итератор; недостижимость через все транзитивные зависимости не доказана. Предупреждение остаётся открытым и не скрывается из audit.

**`proc-macro-error 1.0.4` — [RUSTSEC-2024-0370](https://rustsec.org/advisories/RUSTSEC-2024-0370.html).** Неподдерживаемая транзитивная зависимость макросов GTK3. Это предупреждение о сопровождении, а не подтверждённая уязвимость приложения.

Результат «0 vulnerabilities» не означает, что все предупреждения устранены или что приложение не содержит других ошибок.

## Активные проверки в изолированном WebKit

Проверено 15 отрицательных сценариев через настоящий IPC и renderer:

- Вместо ID трека переданы опция командной строки, путь с `../` и адрес loopback; вместо браузера — строка с shell-разделителем и путь. Все отклонены.
- Переданы неизвестное действие mpv, неправильный тип позиции, неизвестный режим визуализатора и CSS вместо цвета. Все отклонены.
- HTML с обработчиком `onerror` подставлен в названия карточек и текст песни. Он показан текстом; обработчик не исполнился.
- Запрос к недоверенному loopback-адресу и динамическая компиляция JavaScript заблокированы CSP.
- Основное тестовое окно переведено на отдельную локальную HTTP-страницу с недоверенным origin. Попытка вызвать безобидный custom command `status` через Tauri IPC отклонена.

Запрет вызова `status` с недоверенного origin дополнительно подтверждён в финальной production-сборке; после отключения конфигов/плагинов yt-dlp реальный трек воспроизведён через mpv.

Окно входа использует отдельный WebKit-контекст, который WebDriver не перечисляет. Проверка недоверенного origin выполнена на основном тестовом окне; ограничения навигации Google проверены отдельно Rust-тестом, а отсутствие удалённых capability — обзором конфигурации. Проверка не заявляется как атака на серверы Google.

Дополнительные Rust-тесты проверяют подменные домены/схемы/порты, симлинки при записи, область cookies, рекурсивный и чрезмерный YAML, повреждённый KRC. Всего проходят 28 Rust-тестов и 28 поведенческих проверок интерфейса. Ни рабочая Google-сессия, ни cookies пользователя в тесты не копировались.

Повторение: после `regression.py` запусти `python tools/security.py` с теми же WebDriver-переменными из [инструкции](../tools/README.md). Скрипт требует фикстуры и неавторизованный профиль; по завершении удаляет тестовую сессию входа.

## Продолжение: защита профиля

Эксклюзивная блокировка не допускает двух новых экземпляров с одним профилем. Повторный запуск использует приватный Unix socket только для показа существующего окна; канал не принимает аргументы команд или данные сессии. Подробности и оставшиеся ограничения — в [плане beta](BETA.md).

## Границы доверия

- Google-сессия хранится в `~/.config/local.kumite.vesper/`. Идентификатор сохранён для совместимости ранних установок.
- Пароль вводится только на странице Google. neisora не предоставляет интерфейс для чтения cookies в JavaScript.
- YouTube получает запросы рекомендаций и воспроизведения. LRCLIB / KuGou получают метаданные песни для поиска текста; Genius используется как запасной источник обычного текста, Deezer — для поиска обложки. Google cookies и авторизация этим сервисам не передаются. Обложки допускаются только с разрешённых HTTPS CDN; HTML Genius разбирается в текст и не вставляется как HTML в WebView.
- У приложения нет своего облачного сервера, аналитики и сетевого слушателя для управления. Локальный mpv использует Unix socket внутри приватного каталога профиля.
- Секреты хранятся локально в открытом виде, защищённом правами файлов. Это не защищает от компрометации самого пользовательского аккаунта или root.
- mpv, yt-dlp, WebKitGTK, GTK, ImageMagick и Python устанавливаются системой и обновляются отдельно. Аудит lockfile не проверяет их установленный машинный код.
- Импорт браузерной сессии читает браузерные cookies только по явному действию пользователя; сохраняется выбранная YouTube-сессия.

## Повторить проверки

```sh
pnpm audit
cargo install cargo-audit --locked
cargo audit --file src-tauri/Cargo.lock
cargo test --locked --manifest-path src-tauri/Cargo.toml
pnpm check
pnpm build
```

Отдельные проверки WebKit запускаются в изолированном профиле по [инструкции](../tools/README.md). Не прикладывай к issues cookies, подписанные медиассылки, профили браузера или секреты. При сообщении о проблеме достаточно версии, шагов воспроизведения и обезличенного сообщения ошибки.
